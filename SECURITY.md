# Security

Please report vulnerabilities privately, through GitHub's **Report a vulnerability** button on this
repository's Security tab, rather than in a public issue.

Things that are in scope include:

- another local user reaching the terminal daemon's socket or pipe;
- a file, link or preview that runs a program or reaches outside its project;
- anything that makes throng write to a file the user did not ask it to.

Until the first release, only the default branch is supported.
